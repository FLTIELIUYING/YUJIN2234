# YUJIN2234

《余烬 · 2234》角色卡的运行美术与背景音乐资源。

当前资源版本：1.5。包含76份界面、星图、势力徽记与开场图像，以及背景音乐 Frosted Citadel；运行文件合计约14.94MiB。图像和音乐保持卡内原始工作文件的字节与质量。

- `assets/v1.5/`：按SHA-256命名的运行文件。
- `asset-manifest.json`：文件类型、大小、哈希及用途索引。

轻量角色卡使用固定提交版本引用这些文件。更新资源时添加新文件并保留旧版本，可让已经发布的卡继续加载原资源。源图和背景音乐由项目维护者提供，用于本角色卡运行。

## 重要角色立绘

`assets/portraits/v1.9/` 保存33位重要角色的正式PNG立绘，按姓名命名；`portrait-manifest.json`记录人物、尺寸及文件哈希。原图字节保持，未上传设计文稿、参考图、过程稿或聊天内容。角色卡按姓名显示对应立绘，用户自选形象优先。
